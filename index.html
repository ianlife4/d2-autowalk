D2 Survivors 自動走路

用電腦版 Chrome 或 Edge 打開這一頁，把下面這顆按鈕用滑鼠拖到瀏覽器上方的書籤列（看不到書籤列就按 Ctrl+Shift+B）。之前裝過舊版的話，先把舊的「D2繞圈」書籤右鍵刪除。

D2繞圈

⚠ 要用「拖」的。直接點這顆按鈕只會跳出說明，不會裝好。
⚠ 從 LINE、Messenger 點開連結時，請改用 Chrome / Edge 開（內建瀏覽器不能拖曳）。
⚠ 只支援瀏覽器版（d2survivors.lol/play）。下載的桌面版 App 沒有書籤列，不能用。

拖不過去？改用手動新增書籤
  1. 按這顆
  2. 在書籤列上按右鍵 →「新增網頁」（Edge 叫「新增我的最愛」）。
  3. 名稱填 D2繞圈，網址欄按 Ctrl+V 貼上，存檔。

用法

  1. 進遊戲，開始一局。
  2. 點書籤列上的「D2繞圈」→ 右上角出現「自動走路」面板。
  3. 選模式：固定圈／大小圈（每繞一圈隨機換大小）／隨意走（方向慢慢亂轉）。
  4. 按「開始」或在遊戲裡按 F8 開始 / 停止。
  5. 切去別的視窗打字也會繼續走，而且不會干擾你打字。
  6. 看到裝備走過去撿：地上出現金／綠／黃／橘色名字，會先停下來、自動點那個名字讓角色走過去撿，撿完繼續走。8 秒撿不到（例如背包滿）就放棄那件 1 分鐘。顏色可以個別取消勾選。
  7. 藍色預設不勾。勾了會一直按住左 Alt 讓藍色名字從遠處就顯示，每件藍色都走過去（分不出是不是戒指，搭配下面的 Loot Filter 設定：戒指留下、其他賣掉）。

藍色裝備自動賣掉（遊戲內建）

Esc → LOOT FILTER → MAGIC ITEMS 設成 SELL：一踩到藍色裝備就直接賣給 Charsi，錢進帳、不佔背包。護身符（CHARMS）預設是 KEEP，不會被一起賣掉。

想留某一類（例如戒指）：把 RINGS 設成 KEEP。同一件被兩行管到時 KEEP 優先，所以藍色照賣、戒指留下。暗金／套裝看的是 IN MY COLLECTION 那一行。

注意

  • 遊戲視窗不能最小化、也不能被其他視窗整個蓋住（Chrome 會讓看不到的頁面停止，遊戲就停了）。
  • 重新整理網頁後面板會消失，再點一次書籤就好。
  • 升級選卡還是要自己按 1~3。
  • 這是自製工具，不是遊戲官方功能。
